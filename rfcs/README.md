# apimokka — RFC index

RFCs are the design record for apimokka. Each RFC documents a decision, the
alternatives considered, and the tradeoffs accepted. Completed RFCs are not
deleted; they remain indexed in their lifecycle directory as a permanent
record. The lifecycle policy is the MK-000 entry below.

## Numbering

RFCs are numbered from 000. Numbers are assigned on file creation and never
reused. Withdrawn numbers remain in `archive/`; the next RFC takes the next
sequential number.
